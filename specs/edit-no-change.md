# Edit 无变化处理

## 规则与所有者

Edit handler 是编辑结果的唯一所有者。模型提交相同的旧字符串和新字符串，或匹配归一化后得到相同文件内容时，合法的已有文件编辑视为成功的无操作，不返回 NO_CHANGE 失败。

保留路径、文件存在性、大小、Read-before-Edit、过期状态和匹配唯一性检查。不能把缺失文件、错误匹配或过期读取伪装成成功。不存在的文件且两个字符串均为空时返回 FILE_NOT_EXIST。

## 接口与副作用

复用 EditOutput：structuredPatch 为空表示无变化，不新增独立状态字段。模型输出明确说明未写入、无需重复相同编辑；界面沿用成功工具状态。无变化时不调用 writeTextFile、不更新文件时间戳、不补写 memory 元数据，也不更新读状态。

顺序：输入 → 路径/文件/读取状态检查 → 匹配 → 比较结果 → 无变化成功，或原有原子写回。

## 验收

- 相同字符串且匹配有效：成功、空 diff、无写入；模型文本不能声称文件已修改。
- CRLF/LF 或引号归一化后内容不变：同样无写入。
- 缺失文件、未读取、读取过期、匹配缺失：继续返回对应错误。
- 真实修改：仍执行一次写入并返回非空 diff。
