# 创作设置展开与收起

- 生图、生视频、PPT 的生成设置默认展开，可用标题栏按钮收起和重新展开。
- 收起隐藏模式、模型、提示词及附件设置；生成结果、实时进展、停止和保存操作保持可见。
- StudioSettingsDisclosure 是唯一展开状态所有者；该状态仅为组件局部 UI 状态，不进入任务、Host 或服务状态。点击按钮 → 切换局部状态 → 设置区隐藏/显示。
- 子表单保持挂载，收起不清空输入、附件、模型选择，也不中断生成；重新进入面板默认展开。
- 按钮支持键盘 Enter/Space，提供 aria-expanded 与 aria-controls，桌面和移动端共用。
- 验收：展开输入内容 → 收起确认设置不可见、结果仍可见 → 键盘展开确认输入保留；生成过程中同样可切换。
- 不修改生成请求、导出或持久化接口。
