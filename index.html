01 · 源码

工作台占满主区，AI 停在右下。

不用另装编辑器，打开就能用，而且只在本机运行（基于随安装包附带的 code-server）。打开 IDE 后，对话里的草稿、附件和进行中的任务都保留，可以收成一条标题栏。启动失败时会给出退出码和脱敏后的原因，可以重试。

完整工作台

资源管理器、多文件保存、搜索、Git、终端和扩展宿主都在应用里。首次打开不再下载运行时。

把代码交给 AI 对话

选中代码并写上要求，会进入当前工作区的输入草稿。从文件树拖进来的是文件引用，按磁盘上已保存的内容读取。

扩展从 Open VSX 安装

可以粘贴扩展页面链接，或选择本地 VSIX。安装由工作台自己完成。微软商店里的专有扩展不保证可用。

只用于本机工作区

远程工作区这一版没有源码 IDE 入口。网页版也不显示这个按钮。

02 · 成稿

图、视频和幻灯片，在同一个对话框里完成。

不用切换到别的工具。比例、时长和页数按所选模型和你的指定来。生成结果可以留下，也可以存到本地。

先讨论，再生成

意图、美术、挑刺、成稿按顺序发言。成稿的最终提示词单独列出，然后才交给生图或生视频模型。

按页写幻灯片

页数可以指定。一页写完就能预览。深色代码用浅色字。讲流程、分支或步骤的页面自带示意图。

两种 PPT，外加 A4 PDF

可编辑 PPT 按预览量到的位置放文本框。保真 PPT 每一页是一张完整图片，元素不能单独改。全部页面也能导出成 A4 PDF，横页横向，竖页纵向。

历史和局部修改

写完的页留在本机，重新打开可恢复。可以选择元素再交给模型，只替换这些元素。手绘默认出照片；盖在已有照片上时，只改笔迹底下的区域。

03 · 微信

同一套模型，在微信里也能把事情做完。

在微信里发一句话，就能收到图、PDF 或图表。它们走本机已有的网络和任务，文件真正写出来才会发回；失败时会说明停在模型请求、下载还是上传。

出图、PDF 和图表

先判断这是聊天、出图、PDF 还是图表。PDF 和图表写成工作区里的真实文件后再发送。

工作区文件可以发回去

最近绑定的微信会话可以收到工作区里的文件。远程工作区没有文件通道时，不会改在本机执行。

任务可以接着做

紧凑界面可以继续未完成的微信任务，也可以改已经排队的输入。中断之后按检查点继续。

工作区记得说过的话

记忆开启时，原文按工作区留在本机。本机嵌入模型可用时按内容检索；不可用时原文保留，对话继续。

04 · 模型

只接 ZenMux。

需要自备 ZenMux API Key，费用由你自己承担。在欢迎页或设置里填写，加密显示，保存在本机。没有 Key 时给出 ZenMux 邀请链接（https://zenmux.ai/invite/GBQMC5）。 请求发往 zenmux.ai。默认模型包括 openai/gpt-6-sol、anthropic/claude-opus-5.5 和 x-ai/grok-4.7，也可以自己增改。 连接连续失败三次后，可以换到你设置的备用模型。进行中的对话会显示当前在做什么。

常见问题

常见问题

用它要花钱吗？

需要使用你自己的 ZenMux API Key，模型调用的费用由你直接向 ZenMux 支付，用量和计费以 ZenMux 为准。

我的数据会去哪里？

文件留在本机工作区，API Key 加密保存在本机，记忆开启时原文也按工作区留在本机。对话内容会发往 zenmux.ai 用于调用模型。

和 ZCode 有什么区别？

ZenCode 改自智谱开源的 ZCode：产品名改为 ZenCode，模型供应商改为 ZenMux，并加入了内置源码 IDE、成稿和微信能力。

远程工作区能用源码 IDE 吗？

这一版不能。源码 IDE 只用于本机工作区，远程工作区和网页版都不显示入口。
