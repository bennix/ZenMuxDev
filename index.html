ZenCode

桌面端编程助手。界面和运行时来自 ZCode， 模型供应商换成 ZenMux。源码在 bennix/ZenMuxDev。

能做什么

  • 在欢迎页和设置里填写 ZenMux API Key，加密显示并保存在本机。没有 Key 时给出邀请链接。
  • 默认模型为 openai/gpt-6-sol、anthropic/claude-opus-5.5、x-ai/grok-4.7，也可以自己增改模型名和上下文档位。
  • 请求发往 https://zenmux.ai/api/v1，不发送温度参数。
  • 对话框下方可以同时打开「控制电脑」和「控制浏览器」。

源自哪里

ZenCode 改自智谱开源的 ZCode（仓库 zai-org/ZCode）。 本仓库保留原项目结构，把可见产品名改为 ZenCode，并把模型接入改为 ZenMux。 当前源码分支： cursor/zenmux-zencode-provider。
