# 引导式创作与多 Agent 面板

## 产品规则

- 创作和多 Agent 讨论是互斥的辅助面板；打开一个时关闭另一个，输入框仍可使用。
- 创作先呈现作品类型与当前操作提示，再呈现输入和生成动作。模型、画布等细项放在可展开设置内，已有输出不因收起设置而丢失。
- 多 Agent 先呈现任务输入与运行按钮。成员、裁定模型及共享白板是可展开配置；运行中和运行后仍可查看讨论结果。
- 面板在窗口可用高度内滚动，不能越过桌面标题栏或遮挡系统窗口按钮；窄窗口和手机 Web 保持可用。
- 草稿空态使用 ZenCode 字标，不再绘制旧版 Z 线框背景。

## 状态与接口

- `ConversationComposer` 拥有辅助面板打开状态，两个布尔值同一事件内互斥更新。
- 各面板拥有自己的表单草稿和折叠状态。现有生成和讨论调用接口保持不变；不增加第二条写入路径。
- 面板高度由 composer 布局约束，内容滚动发生在面板内部。

## 验收场景

1. 打开创作，再打开多 Agent：只显示后者；反向操作相同。
2. 在 macOS 小窗口和手机宽度打开任一面板：标题栏可见，面板内容可滚动到末尾，发送按钮仍可用。
3. 首次打开创作：能先看到作品类型和下一步提示；收起高级配置后，已输入内容不丢失。
4. 首次打开多 Agent：先看到任务输入和运行入口；配置可以按需展开，讨论输出可见。
5. 草稿空态在亮色、暗色主题显示 ZenCode 字标，不再出现旧版浅色 Z 水印。
