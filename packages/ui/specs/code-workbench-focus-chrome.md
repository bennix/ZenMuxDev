# IDE 专注模式的浏览器控件

## 产品规则

- 只有内置 IDE 的专注模式隐藏侧面板标签栏、浏览器地址导航栏和响应式视口工具栏。普通浏览器标签仍显示这些控件。
- macOS 原生窗口按钮所在的顶部 48px 区域保持空白且可拖动；IDE 网页从该区域下方开始，不能与红黄绿窗口按钮重叠。
- 退出 IDE 专注模式后恢复原有控件与导航草稿；切换显示状态不卸载浏览器 guest、标签或对话草稿。

## 状态与接口

- `WorkspaceShellLayout` 继续作为 IDE 专注状态的唯一所有者，通过已有 `data-code-workbench-focus` 布局属性驱动显示规则。
- 标签栏、导航栏和网页只改变可见性或布局，不修改浏览器导航、历史、截图及 Agent 控制接口。

## 验收场景

1. macOS IDE 专注模式：红黄绿按钮下方没有标签文字或操作按钮，地址导航栏不可见，网页内容从安全区域下方显示。
2. 退出专注模式：标签栏与地址导航栏恢复，网页与 AI 草稿没有重新挂载或丢失。
3. 普通内置浏览器标签：标签栏和地址导航栏正常显示。
